一条 SQL 怎么跑（基础与架构）→ 索引为什么快（索引原理）→ 数据怎么存（存储引擎）→ 事务怎么保证一致（事务与隔离）→ 并发读写怎么不冲突（MVCC + 锁）→ 崩了怎么恢复（日志体系）→ 慢了怎么治（SQL 优化）→ 单机扛不住怎么办（高可用 + 分库分表 + 调优）→ 真实业务怎么设计（实战场景）。
