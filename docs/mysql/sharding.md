## 计划内容

- [ ] 为什么要拆分：单表数据量、单库连接数与 QPS 瓶颈
- [ ] 垂直拆分：垂直分库（按业务）、垂直分表（按列）
- [ ] 水平拆分：水平分库、水平分表，数据如何路由
- [ ] 分片键选择：如何选 sharding key，避免跨片查询与热点
- [ ] 分片算法：范围分片、Hash 取模、一致性哈希、查表法
- [ ] 分布式 ID 方案：UUID、数据库自增段、雪花算法 Snowflake、Leaf
- [ ] 分库分表后的难题：跨片 join、跨片分页排序、跨片事务、全局聚合
- [ ] 跨片分页查询的优化方案
- [ ] 扩容难题：翻倍扩容、双写迁移、一致性哈希减少迁移
- [ ] 常用中间件：ShardingSphere、MyCat、Vitess，客户端分片 vs 代理分片
- [ ] 什么时候不该分库分表：先考虑归档、读写分离、缓存
