# 88. 合并两个有序数组

> LC 88 · Merge Sorted Array · 双指针（逆向）

## 题目

给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。

**注意：** 最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0`，应忽略。`nums2` 的长度为 `n`。

**示例 1：**
```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6] ，结果是 [1,2,2,3,5,6]。
```

**示例 2：**
```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
解释：nums2 为空，不需要合并。
```

**示例 3：**
```
输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
解释：数组 m=0 说明 nums1 中没有有效元素，nums1 中的 0 仅为占位，合并后是 [1]。
```

**约束：**
- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10⁹ <= nums1[i], nums2[j] <= 10⁹`

核心思想：**两个数组都有序，且 nums1 尾部有足够的空位——那么从大到小、从后往前填充，每次取 `nums1[p1]` 和 `nums2[p2]` 中较大的那个放到 `nums1[p]`，一定不会覆盖掉还没处理的元素。**

## 解题思路 — 先想最直观的做法，再想最优

拿到这道题，我第一个想法：把 nums2 直接塞到 nums1 末尾的空白区，然后 sort 一下。

```java
for (int i = 0; i < n; i++) {
    nums1[m + i] = nums2[i];
}
Arrays.sort(nums1);
```

时间 O((m+n) log(m+n))，空间 O(1)。能过，但面试官显然不满意——两个数组本身已经有序了，sort 完全浪费了这个条件。

那我换个想法：用两个指针从头开始，哪个小就放哪个。但问题来了——合并结果要存回 nums1，从头放会覆盖掉 nums1 原有的元素。除非我开一个额外数组暂存……那样空间就变成 O(m+n) 了。

等等。**为什么一定要从前往后？** nums1 尾部有空位，从大到小、从后往前填不就行了？这样永远不会覆盖掉还没处理的元素——因为 `p` 始终在 `p1` 的右侧（或等于），nums1[0..p1] 的元素在自然结束前不会被覆盖。

好，方向定了：**逆向双指针。**

## 代码推演 — ACM 模式，逐步构建

### 第一步：读入数据

ACM 模式下，输入格式是怎样的？题目给的格式是：

- 第一行：`m` 和 `n`
- 第二行：`m+n` 个整数 (nums1)
- 第三行：`n` 个整数 (nums2)

但也可能是这样的简化格式：

- 第一行：`m n`
- 第二行：`nums1[0] nums1[1] ... nums1[m+n-1]`
- 第三行：`nums2[0] nums2[1] ... nums2[n-1]`

我先按这个格式来写。先搭骨架：

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[] nums1 = new int[m + n];
        int[] nums2 = new int[n];

        for (int i = 0; i < m + n; i++) {
            nums1[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            nums2[i] = sc.nextInt();
        }
        sc.close();
    }
}
```

等等，nums1 的后 n 个位置是占位 0——用户也会输入 0 吗？按题目的意思，第二行会输入 `m+n` 个数，其中后 n 个是 0。这个没问题，我们还是要覆盖它们。

---

### 第二步：核心方法——逆向双指针

我需要三个指针，都从数组尾部开始：

- `p1 = m - 1` → nums1 最后一个有效元素的索引
- `p2 = n - 1` → nums2 最后一个元素的索引
- `p = m + n - 1` → nums1 的最后一个位置（从这里开始填）

循环的条件是什么？当 `p2 >= 0` 时继续。为什么只判断 p2？因为如果 p2 先变成负数，说明 nums2 已经全部合并完了，nums1 剩下的元素本来就在正确位置，不需要动。

但是——还有一个情况：如果 p1 先变成负数（nums1 的有效元素先用完了），但 p2 还没处理完，怎么办？这时候 nums1[p1] 已经不存在了，就不能比较了，应该直接把 nums2[p2] 填到 nums1[p]。

所以循环体里需要先判断 p1 是否还有效：

```java
    public static void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;
        int p2 = n - 1;
```

### 完整代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[] nums1 = new int[m + n];
        int[] nums2 = new int[n];

        for (int i = 0; i < m + n; i++) {
            nums1[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            nums2[i] = sc.nextInt();
        }
        sc.close();

        merge(nums1, m, nums2, n);

        for (int i = 0; i < m + n; i++) {
            System.out.print(nums1[i]);
            if (i < m + n - 1) System.out.print(" ");
        }
    }

    public static void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1;       // nums1 有效元素的末尾
        int p2 = n - 1;       // nums2 的末尾
        int p = m + n - 1;    // nums1 尾部填充位置

        while (p2 >= 0) {
            if (p1 >= 0 && nums1[p1] > nums2[p2]) {
                nums1[p] = nums1[p1];
                p1--;
            } else {
                nums1[p] = nums2[p2];
                p2--;
            }
            p--;
        }
    }
}
```

### 边界验证

- **n=0（nums2 为空）**：while 条件 `p2 >= 0` 即 `-1 >= 0` 为 false，不进入循环，nums1 原封不动。正确。
- **m=0（nums1 无有效元素）**：p1 = -1。每次比较时 `p1 >= 0` 为 false，全部走 else 分支，把 nums2 的元素从后往前搬过去。正确。
- **全部元素相等**：比如 `nums1=[1,1,0], m=2, nums2=[1], n=1`。p1=1, p2=0, p=2。`nums1[1]=1 > nums2[0]=1`？不成立（1 不大于 1），走 else，nums1[2]=1，p2=-1 结束循环。nums1=[1,1,1]。正确。

**两个有序数组合并且 nums1 尾部有空位 → 逆向双指针，从大到小填，永远不会覆盖未处理的元素，时空 O(m+n) / O(1)。**
