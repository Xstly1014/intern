## 刷题建议

1. **先数据结构后算法**：数组 → 链表 → 栈/队列 → 哈希 → 树 → 堆 → 图，再学算法。
2. **同一类型集中刷**：比如链表题一次性刷完，形成肌肉记忆。
3. **每道题先自己想 5 分钟**，没头绪再看思路，理解了再手写代码。
4. **反复刷**：第一遍看思路，第二遍独立写出，第三遍优化代码。
5. **重点标记**：标记做错的题，隔一周重做。
