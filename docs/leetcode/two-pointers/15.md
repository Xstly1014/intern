# 15. 三数之和

> LC 15 · 3Sum · 排序 + 双指针

## 题目

给你一个包含 `n` 个整数的数组 `nums`，判断 `nums` 中是否存在三个元素 `a, b, c`，使得 `a + b + c = 0`。请你找出所有和为 `0` 且 **不重复** 的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0
不同的三元组是 [-1,0,1] 和 [-1,-1,2]，注意输出的顺序不重要。
```

**示例 2：**
```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0。
```

**示例 3：**
```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0。
```

**约束：**
- `3 <= nums.length <= 3000`
- `-10⁵ <= nums[i] <= 10⁵`

核心流程：**排序 → 固定一个数 i → 在剩余区间用双指针 L、R 查找两数之和等于 `-nums[i]`。** 找到后 L++、R-- 继续搜索，同时跳过所有重复值。排序是去重的关键——有序数组让"跳过相同值"变得简单。

注意：排序后 i、L、R 三层去重缺一不可，否则会产出重复三元组。

## 解题思路 — 从暴力到最优

拿到这道题，第一个想法：三层循环枚举所有三元组，和为 0 就加进结果，最后去重。

```java
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        for (int k = j + 1; k < n; k++)
            if (nums[i] + nums[j] + nums[k] == 0)
                add to result
```

时间 O(n³)，n 最大 3000，3000³ = 2.7×10¹⁰，肯定不行。

怎么优化？"三数之和"可以转化成"固定一个数 + 找另外两个数"。固定 nums[i] 后，问题变成在剩余的 n-1 个元素中找两个数之和等于 `-nums[i]`——这是经典的"两数之和"问题。

两数之和可以用 HashMap 做到 O(n)，但需要额外空间。而且还要处理去重，用 HashMap 去重比较麻烦。

还有没有更好的方法？如果把数组**排序**，就可以用**双指针**解决"两数之和"：L 从 i+1 开始，R 从 n-1 开始，`sum = nums[L] + nums[R]`。如果 sum < target，说明 L 需要变大 → L++；如果 sum > target，说明 R 需要变小 → R--。找到相等时记录结果，然后 L++ 和 R-- 继续找。

排序还有个额外好处——相同的值会连在一起，去重只需要比较前后元素是否相等，简单高效。

方向定了：**排序 + 双指针。**

### 第四步：双指针搜索

固定 i 之后，在 `[i+1, n-1]` 区间内用 L、R 双指针：

```java
            int left = i + 1;
            int right = nums.length - 1;
```

### 完整代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        sc.close();

        List<List<Integer>> result = threeSum(nums);

        for (List<Integer> triplet : result) {
            System.out.println(triplet.get(0) + " " + triplet.get(1) + " " + triplet.get(2));
        }
    }

    public static List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();

        for (int i = 0; i < nums.length - 2; i++) {
            // 去重 1：跳过与上一个相同的 i
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;
            int target = -nums[i];

            while (left < right) {
                int sum = nums[left] + nums[right];

                if (sum < target) {
                    left++;
                } else if (sum > target) {
                    right--;
                } else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));

                    // 找到一组解后移动指针并跳过重复
                    left++;
                    right--;

                    // 去重 2 & 3：跳过 L 和 R 的重复值
                    while (left < right && nums[left] == nums[left - 1]) {
                        left++;
                    }
                    while (left < right && nums[right] == nums[right + 1]) {
                        right--;
                    }
                }
            }
        }

        return result;
    }
}
```

### 边界验证

- **不足 3 个元素**：`nums.length < 3`，for 循环条件 `i < nums.length - 2` 不满足，不进入，返回空 list。正确。
- **全相同 `[0,0,0]`**：排序后 `[0,0,0]`。i=0 第一次循环：left=1, right=2, sum=0+0=0 == target=0，找到 `[0,0,0]`。left=2, right=1，while 退出。i=1 时 `nums[1]=0 == nums[0]=0`，continue。最终返回一个解。正确。
- **无解 `[1,2,-3]`**：排序 `[-3,1,2]`。i=0：target=3, L=1(num=1), R=2(num=2), sum=3 == target，找到 `[-3,1,2]`。有一个解。……等等，`[-3,1,2]` 和确实为 0。正确。
- **全正 `[1,2,3,4]`**：排序后 `[1,2,3,4]`。i=0：target=-1, sum 至少 3 > -1，一直 right-- 到 left=right 无解。i=1：target=-2，无解。i=2：target=-3，无解。返回空。正确。

## 一句话总结

**排序 + 固定 i + 双指针 L/R 反向扫描，sum < target 则 L++，sum > target 则 R--，找到后 L++ R-- 并三重跳过重复值（i 重复/L 重复/R 重复），将三数之和从 O(n³) 降到 O(n²)。**
