# 42. 接雨水

> LC 42 · Trapping Rain Water · 前后缀分解 / 双指针

## 题目

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**
```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：柱状图如下，蓝色部分能接住 6 个单位的雨水。
```

**示例 2：**
```
输入：height = [4,2,0,3,2,5]
输出：9
```

**约束：** `n == height.length`，`1 <= n <= 2 * 10^4`，`0 <= height[i] <= 10^5`

核心公式：`water[i] = min(leftMax[i], rightMax[i]) - height[i]`。水位线由左右最高柱子的较小值决定，因为水总是从较低的一侧溢出。每一列的含水量 = 水位线 - 柱子高度。

---

## 解题思路 — 从直觉到公式

拿到这道题，第一个直觉：一个位置能接多少水，取决于它左右两边最高的柱子。两边的最高柱子像两堵墙，水的高度就是较矮那堵墙的高度减去当前柱子的高度。

暴力做法：对每个位置 i，分别向左和向右扫描找最高柱子。时间 O(n²)，n=2×10⁴ 勉强但不够漂亮。

优化：预计算每根柱子左右两边的最大值——即 leftMax 数组和 rightMax 数组。leftMax[i] = max(height[0..i])，rightMax[i] = max(height[i..n-1])。两趟 O(n) 扫描 + 一趟 O(n) 累加，总 O(n)，空间 O(n)。

这就是**前后缀分解**——把"向左找最大"和"向右找最大"这两个动作预处理成数组，每个位置 O(1) 取值计算水量。

还能用**双指针**进一步将空间优化到 O(1)：L 从左边扫、R 从右边扫，只维护 leftMax 和 rightMax 两个变量而非整个数组。哪个方向的 max 更小就先处理哪边——因为水量由较小的一边决定。

方向定了。下面逐步构建代码。

### 第三步：前后缀分解实现

先处理边界——空数组直接返回 0：

```java
        int n = height.length;
        if (n == 0) return 0;
```

嗯，题目 n ≥ 1，但防御性编程加一个没问题。

创建 leftMax 和 rightMax：

```java
        int[] leftMax = new int[n];
        int[] rightMax = new int[n];
```

填 leftMax——从左到右：

```java
        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) {
            leftMax[i] = Math.max(leftMax[i - 1], height[i]);
        }
```

等等，leftMax[i] 的含义是"位置 0..i 的最大值"。那 leftMax[0] 就是 height[0] 本身，没问题。

填 rightMax——从右到左：

```java
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMax[i] = Math.max(rightMax[i + 1], height[i]);
        }
```

现在遍历计算水量。每个位置的水 = `min(leftMax[i], rightMax[i]) - height[i]`。由于 leftMax[i] 和 rightMax[i] 都 ≥ height[i]，差一定 ≥ 0，不需要额外的 if 判断。

```java
        int water = 0;
        for (int i = 0; i < n; i++) {
            water += Math.min(leftMax[i], rightMax[i]) - height[i];
        }
        return water;
```

验证一下极端情况：
- 单柱子 `[5]`：n=1，leftMax[0]=5, rightMax[0]=5, min=5, water=5-5=0。正确。
- 递增 `[1,2,3]`：leftMax=[1,2,3], rightMax=[3,3,3], min=[1,2,3], water=0+0+0=0。正确——递增不积水。
- 递减 `[3,2,1]`：leftMax=[3,3,3], rightMax=[3,2,1], min=[3,2,1], water=0+0+0=0。正确——递减不积水。
- 凹槽 `[2,0,2]`：leftMax=[2,2,2], rightMax=[2,2,2], min=[2,2,2], water=0+2+0=2。正确。

### 完整代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] height = new int[n];
        for (int i = 0; i < n; i++) {
            height[i] = sc.nextInt();
        }
        sc.close();

        System.out.println(trap(height));
    }

    public static int trap(int[] height) {
        int n = height.length;
        if (n == 0) return 0;

        int[] leftMax = new int[n];
        int[] rightMax = new int[n];

        // leftMax[i] = max(height[0..i])
        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) {
            leftMax[i] = Math.max(leftMax[i - 1], height[i]);
        }

        // rightMax[i] = max(height[i..n-1])
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMax[i] = Math.max(rightMax[i + 1], height[i]);
        }

        int water = 0;
        for (int i = 0; i < n; i++) {
            water += Math.min(leftMax[i], rightMax[i]) - height[i];
        }
        return water;
    }
}
```

## 复杂度分析

| 维度 | 复杂度 | 说明 |
|---|---|---|
| 时间 | O(n) | 三次遍历（leftMax、rightMax、累加），各 O(n) |
| 空间 | O(n) | leftMax 和 rightMax 两个额外数组 |

（双指针优化版可做到 O(1) 空间，面试中讲完前后缀分解后可以提及，不需现写。）

## 一句话总结

**每根柱子能接的水 = `min(左边最高, 右边最高) - 自身高度`，通过前后缀分解预处理 leftMax 和 rightMax 做到 O(n) 时间。**
