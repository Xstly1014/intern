# 3. 无重复字符的最长子串

> LC 3 · Longest Substring Without Repeating Characters · 滑动窗口

## 题目

给定一个字符串 `s`，请你找出其中不含有重复字符的 **最长子串** 的长度。

**示例 1：**
```
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

**示例 2：**
```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3：**
```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串。
```

**约束：** `0 <= s.length <= 5 * 10^4`，`s` 由英文字母、数字、符号和空格组成。

## 解题思路 — 从模糊到清晰

拿到这道题，我第一个反应是——"子串"意味着字符必须**连续**。要找最长的不含重复字符的子串。

暴力做法？两层循环枚举所有子串 O(n²)，再内层判断是否无重复 O(n)，总 O(n³)。题目约束 n ≤ 5×10⁴，这肯定不行。

n 达到 5 万级别，必须是 O(n) 或者 O(nlogn)。

再看题目特征——"子串 + 不重复"，这是一个典型的**滑动窗口**信号。滑动窗口专门解决"连续子数组/子串满足某种约束条件"的问题。

窗口内需要快速判断"这个字符当前是否在窗口中"。HashSet 可以做到 O(1) 增删查，但需要处理"收缩窗口时删除左指针扫过的字符"。另一种做法是用一个数组记录每个字符**最近一次出现的位置**，如果这个位置在当前左指针范围内，说明重复了。这道题字符集是 ASCII（≤ 128），数组比 HashSet 更快。

### 核心方法第一步：我需要什么数据结构？

关键是：当 `right` 向右移动时，要能**快速判断当前字符是否已经在窗口中**。

两个选项：

1. **HashSet** — 存窗口内的所有字符，收缩时删除左指针扫过的字符
2. **数组记录最近位置** — 用 `int[128]` 存每个 ASCII 字符最近一次出现的位置，判断"这个位置 ≥ left 吗"

等等……用 HashSet 的话，收缩窗口时需要知道删除哪个字符。HashSet 可以做到，但数组方案更简洁——不需要显式增删，只需要判断 `lastIndex[字符] >= left` 就行。而且 `int[128]` 的访问比 HashMap 的哈希计算更快。

就选数组方案。初始全设为 -1，表示从未出现过。

```java
        int[] lastIndex = new int[128];
        // 怎么初始化全为 -1？
```

直接 new 出来的 int 数组默认是 0，不是 -1。我得用 `Arrays.fill`。

```java
        int[] lastIndex = new int[128];
        Arrays.fill(lastIndex, -1);
```

好，数据结构有了。

### 核心方法第三步：循环体内做什么？

`right` 每走一步，取到当前字符 `c`：

```java
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
```

现在判断这个 `c` 是否已经在当前窗口中。怎么判断？看 `lastIndex[c]`——如果 `lastIndex[c] >= left`，说明 `c` 在当前窗口里出现过（因为这个位置在左指针的范围内）。

等等，还得想一下这个逻辑对不对。假如 `s = "abcabcbb"`，`c = 'a'` 第一次出现时 `lastIndex['a'] = 0`，`left = 0`，所以 `0 >= 0` 成立，会触发收缩——但这不对！第一次出现不应该收缩。

……等一下，我说错了。第一次出现时 `lastIndex['a']` 初始是 -1（因为我用 `Arrays.fill` 设了 -1），`-1 >= 0` 是 false，不会触发。然后我把 `lastIndex['a']` 更新为 0。下一次再遇到 'a' 时，`lastIndex['a'] = 0 >= left(0)`，这时才触发。逻辑是对的。

```java
            if (lastIndex[c] >= left) {
                // 重复了！需要收缩
                left = lastIndex[c] + 1;  // L 跳到重复字符的下一个位置
            }

            lastIndex[c] = right;  // 更新最新位置
            maxLen = Math.max(maxLen, right - left + 1);  // 更新最大长度
        }
```

这里有个关键细节：`left = lastIndex[c] + 1`，不是 `left++`。为什么？因为重复字符出现的位置可能在窗口中间，比如 `"abcadef"`，'a' 重复时 left 必须直接跳到 `lastIndex['a'] + 1 = 1`，即 'b' 的位置。如果只是 `left++` 一次，窗口 `[a,b,c,a]` 收缩成 `[b,c,a]`，但第一个 'a' 还在窗口里吗……不对，`left++` 只能去掉 'a'，因为 `left` 从 0 变成 1，'a' 的索引是 0，0 < 1，所以 'a' 确实不在窗口了。

但 `left++` 的问题是：如果重复字符不在窗口最左侧，比如 `"abcdb"` → `lastIndex['b'] = 1`，`left` 如果是 0，`left++` 变成 1，去掉的是 'a'，但重复的是 'b' 在位置 1——那窗口 `[b,c,b]` 还是重复！必须跳到 `lastIndex['b'] + 1 = 2`，窗口才变成 `[c,b]`。

所以必须 `left = lastIndex[c] + 1`，不能 `left++`。**这是一个很容易写错的点。**

### 完整代码

把上面逐步推演的部分组装起来：

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine();
        sc.close();

        int result = lengthOfLongestSubstring(s);
        System.out.println(result);
    }

    public static int lengthOfLongestSubstring(String s) {
        // lastIndex[c] 记录字符 c 最近一次出现的位置，初始 -1 表示从未出现
        int[] lastIndex = new int[128];
        Arrays.fill(lastIndex, -1);

        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);

            // 当前字符已在窗口中出现过 → 收缩左边界
            if (lastIndex[c] >= left) {
                left = lastIndex[c] + 1;
            }

            lastIndex[c] = right;                         // 更新位置
            maxLen = Math.max(maxLen, right - left + 1);  // 更新最大长度
        }

        return maxLen;
    }
}
```

---

### 边界验证

写完代码需要过一遍边界：

- **空串 `""`**：`s.length()=0`，for 循环不执行，直接返回 `maxLen=0`。正确。
- **单字符 `"a"`**：`right=0`，`lastIndex['a']=-1`，不触发收缩；`lastIndex['a']=0`，`maxLen=max(0, 0-0+1)=1`。返回 1。正确。
- **全重复 `"bbbbb"`**：第一次 'b'：不触发，更新 `lastIndex['b']=0`，max=1。第二次 'b'：`lastIndex['b']=0 >= left=0`，触发！`left=1`，更新 `lastIndex['b']=1`，max=max(1, 1-1+1)=1。依此类推，每次都触发收缩，max 始终 1。正确。
- **无重复 `"abcdef"`**：每次 `lastIndex[c]` 都是 -1，不触发收缩，窗口持续扩大。最终 maxLen=6。正确。

## 复杂度分析

| 维度 | 复杂度 | 说明 |
|---|---|---|
| 时间 | O(n) | `right` 从 0 到 n-1 遍历一次，`left` 只增不减（最多到 n），每个字符操作 O(1) |
| 空间 | O(1) | `int[128]` 固定大小，不随输入规模变化（HashMap 也是 O(字符集大小)=O(1)） |

---

## 一句话总结

**滑动窗口 + int[128] 记录最近位置：左指针在遇到重复时直接跳到 `lastIndex[c] + 1`（不是 `left++`），保证窗口始终无重复，过程中取窗口长度的最大值。**
