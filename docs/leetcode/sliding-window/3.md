# 3. 无重复字符的最长子串

> LC 3 · Longest Substring Without Repeating Characters · 滑动窗口

## 题目

给定一个字符串 `s`，请你找出其中不含有重复字符的 **最长子串** 的长度。

**示例 1：**
```
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

**示例 2：**
```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3：**
```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串。
```

**约束：** `0 <= s.length <= 5 * 10^4`，`s` 由英文字母、数字、符号和空格组成。

---

## 图解滑动窗口

```
s = "abcabcbb"，滑动窗口过程：

窗口 [a]                 max=1,  set={a}
窗口 [a,b]               max=2,  set={a,b}
窗口 [a,b,c]             max=3,  set={a,b,c}
窗口 [a,b,c,a] → 发现 a 重复!
  → 左指针右移，收缩窗口直到 a 被移出
  → 窗口 [b,c,a]         max=3,  set={b,c,a}
窗口 [b,c,a,b] → 发现 b 重复!
  → 左指针右移，窗口 [c,a,b]  max=3,  set={c,a,b}
窗口 [c,a,b,c] → 发现 c 重复!
  → 左指针右移，窗口 [a,b,c]  max=3,  set={a,b,c}
窗口 [a,b,c,b] → 发现 b 重复!
  → 左指针右移，窗口 [c,b]    max=3,  set={c,b}
窗口 [c,b,b] → 发现 b 重复!
  → 左指针右移，窗口 [b]      max=3,  set={b}

最终答案: 3
```

核心思想：右指针不断向右扩展，遇到重复字符时左指针收缩到重复字符的下一个位置，窗口内始终无重复。答案取窗口长度的最大值。

---

## 解题思路

暴力做法：枚举所有子串 O(n²)，判断是否无重复 O(n)，总 O(n³)，5×10⁴ 数据量不可行。

这道题的信号非常明确——**子串 + 约束条件（无重复）**，典型**滑动窗口**。

用一个 `int[128]` 数组记录每个字符最近一次出现的位置（ASCII 足够覆盖所有合法字符）。左右指针 `left` 和 `right` 维护窗口，`right` 遍历字符串，当 `s[right]` 已在当前窗口中时（`lastIndex[c] >= left`），`left` 跳到重复字符的下一个位置。

- 时间 O(n)：每个字符最多被左右指针各访问一次
- 空间 O(1)：`int[128]` 固定大小

---

## 代码实现（ACM 模式）

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine();
        sc.close();

        int result = lengthOfLongestSubstring(s);
        System.out.println(result);
    }

    public static int lengthOfLongestSubstring(String s) {
        // lastIndex[c] = 字符 c 最近一次出现的位置，-1 表示从未出现
        int[] lastIndex = new int[128];
        Arrays.fill(lastIndex, -1);

        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);

            // 当前字符已经在窗口中出现过 → 收缩左边界
            if (lastIndex[c] >= left) {
                left = lastIndex[c] + 1;
            }

            lastIndex[c] = right;
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

---

## 复杂度分析

| 维度 | 复杂度 | 说明 |
|---|---|---|
| 时间 | O(n) | `right` 遍历一遍，`left` 单调右移，每个字符最多访问两次 |
| 空间 | O(1) | `int[128]` 固定大小，不随输入规模变化 |

---

## 一句话总结

**滑动窗口 + int[128] 记录字符最近位置：右指针扩展窗口、左指针在遇到重复时跳到重复字符的下一个位置，保证窗口内始终无重复，过程中取窗口长度的最大值。**
