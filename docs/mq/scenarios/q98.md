# Q98 Agent 事件驱动

Agent 事件驱动架构将"感知(Perception)→决策(Decision)→执行(Execution)→记忆(Memory)"四大模块通过 MQ 完全解耦，核心流程是：用户输入触发 user.message 事件 → 决策模块消费并调用 LLM 生成回复（流式 chunk）→ 发布 llm.reply 事件 → 执行模块消费并调用工具/API → 发布 tool.result 事件 → 记忆模块消费并写入向量库。与传统业务消息有五大区别：消息结构复杂（对话上下文/工具参数/思考链）、流式处理（LLM 输出分 chunk）、延迟敏感（用户等回复）、多模态（文本/图片/音频）、状态关联需 session_id。选型上 Agent 模块间用 Disruptor 内存队列，跨服务用 RabbitMQ Topic Exchange 低延迟路由，trace 日志用 Kafka 高吞吐。

## 代码实现：Agent 事件定义、发布、LLM 流式回复、向量记忆写入

### Layer 1 — Agent 事件定义（UserMessageEvent / LLMReplyEvent / ToolResultEvent）

```java
// ============ 基础 Agent 事件抽象 ============
@Data
public abstract class AgentEvent {
    private String eventId;       // UUID，事件唯一标识
    private String sessionId;     // 对话会话 ID，贯穿全部事件
    private String traceId;       // 分布式链路追踪 ID
    private Instant timestamp;    // 事件时间戳
    private String agentId;       // Agent 实例 ID
}

// ============ 用户消息事件 ============
@Data
@EqualsAndHashCode(callSuper = true)
public class UserMessageEvent extends AgentEvent {
    public static final String EVENT_TYPE = "agent.user.message";

    private String contentType;   // text / image / audio / video
    private String content;       // 消息内容（文本或 base64）
    private String fileUrl;       // 多模态文件 URL
    private List<Message> history; // 多轮对话上下文
}

// ============ LLM 回复事件（支持流式 chunk） ============
@Data
@EqualsAndHashCode(callSuper = true)
public class LLMReplyEvent extends AgentEvent {
    public static final String EVENT_TYPE = "agent.llm.reply";

    private String replyId;
    private String model;         // gpt-4 / claude-3.5 / deepseek-v3
    private String content;       // 当前 chunk 内容
    private int chunkIndex;       // 第几个 chunk（0-based）
    private boolean isLast;       // 是否为最后一个 chunk
    private String reasoningChain; // Chain-of-Thought 思考链
    private int tokenUsed;        // 当前累计 Token 消耗
}

// ============ 工具执行结果事件 ============
@Data
@EqualsAndHashCode(callSuper = true)
public class ToolResultEvent extends AgentEvent {
    public static final String EVENT_TYPE = "agent.tool.result";

    private String toolName;          // 工具名称：web_search / code_exec / api_call
    private Map<String, Object> params;  // 工具入参
    private Object result;            // 工具返回结果
    private boolean success;          // 执行是否成功
    private String errorMessage;      // 失败原因
    private long durationMs;          // 工具调用耗时
}
```

### Layer 2 — 感知模块发布事件（RabbitMQ Topic Exchange + session_id header）

```java
// ============ RabbitMQ Agent 事件配置 ============
@Configuration
public class AgentEventMqConfig {

    public static final String EXCHANGE_AGENT = "exchange.agent.event";

    @Bean
    public TopicExchange agentEventExchange() {
        return new TopicExchange(EXCHANGE_AGENT, true, false);
    }

    // ============ 决策模块队列（消费 user.message） ============
    @Bean
    public Queue decisionQueue() {
        return QueueBuilder.durable("queue.agent.decision")
                .build();
    }

    @Bean
    public Binding decisionBinding() {
        return BindingBuilder.bind(decisionQueue())
                .to(agentEventExchange())
                .with("agent.user.message");      // routing key 匹配
    }

    // ============ 执行模块队列（消费 llm.reply） ============
    @Bean
    public Queue executionQueue() {
        return QueueBuilder.durable("queue.agent.execution").build();
    }

    @Bean
    public Binding executionBinding() {
        return BindingBuilder.bind(executionQueue())
                .to(agentEventExchange())
                .with("agent.llm.reply");
    }

    // ============ 记忆模块队列（消费 tool.result） ============
    @Bean
    public Queue memoryQueue() {
        return QueueBuilder.durable("queue.agent.memory").build();
    }

    @Bean
    public Binding memoryBinding() {
        return BindingBuilder.bind(memoryQueue())
                .to(agentEventExchange())
                .with("agent.tool.result");
    }

    // ============ Trace 队列（消费所有事件，Kafka 替代） ============
    @Bean
    public Queue traceQueue() {
        return QueueBuilder.durable("queue.agent.trace").build();
    }

    @Bean
    public Binding traceBinding() {
        return BindingBuilder.bind(traceQueue())
                .to(agentEventExchange())
                .with("agent.#");          // 通配：消费所有 agent.* 事件
    }
}

// ============ 感知模块：接收用户输入 → 发布 user.message 事件 ============
@Component
@RequiredArgsConstructor
public class PerceptionModule {
    private final RabbitTemplate rabbitTemplate;

    public void onUserInput(String sessionId, String content, String contentType) {
        UserMessageEvent event = new UserMessageEvent();
        event.setEventId(UUID.randomUUID().toString());
        event.setSessionId(sessionId);
        event.setTraceId(UUID.randomUUID().toString());
        event.setTimestamp(Instant.now());
        event.setAgentId("agent-01");
        event.setContentType(contentType);
        event.setContent(content);

        // 加载多轮对话历史
        event.setHistory(chatHistoryService.getHistory(sessionId, 10));

        // 发布事件：routing key = agent.user.message
        rabbitTemplate.convertAndSend(
            AgentEventMqConfig.EXCHANGE_AGENT,
            "agent.user.message",
            event,
            msg -> {
                // header 注入 session_id，便于消费者按会话路由
                msg.getMessageProperties().setHeader("session_id", sessionId);
                msg.getMessageProperties().setHeader("trace_id", event.getTraceId());
                return msg;
            }
        );
        log.info("[Perception] session={} user.message 事件已发布", sessionId);
    }
}
```

### Layer 3 — LLM 流式回复事件（chunk 分片发送，前端 SSE 展示）

```java
// ============ 决策模块：消费 user.message → 调用 LLM → 流式发布 llm.reply ============
@Component
@RequiredArgsConstructor
public class DecisionModule {
    private final RabbitTemplate rabbitTemplate;
    private final OpenAiService openAiService;

    private static final String ROUTING_KEY = "agent.llm.reply";

    @RabbitListener(queues = "queue.agent.decision")
    public void onUserMessage(UserMessageEvent event) {
        String sessionId = event.getSessionId();
        String traceId = event.getTraceId();
        String replyId = UUID.randomUUID().toString();

        log.info("[Decision] session={} trace={} 收到用户消息，开始 LLM 推理", sessionId, traceId);

        // ============ 流式调用 LLM ============
        Flux<String> stream = openAiService.chatStream(
            ChatRequest.builder()
                .model("gpt-4")
                .messages(event.getHistory())
                .userMessage(event.getContent())
                .build()
        );

        AtomicInteger chunkIndex = new AtomicInteger(0);
        AtomicInteger totalTokens = new AtomicInteger(0);

        stream.doOnNext(chunk -> {
            int idx = chunkIndex.getAndIncrement();
            totalTokens.addAndGet(estimateTokens(chunk));

            LLMReplyEvent replyEvent = new LLMReplyEvent();
            replyEvent.setEventId(UUID.randomUUID().toString());
            replyEvent.setSessionId(sessionId);
            replyEvent.setTraceId(traceId);
            replyEvent.setAgentId(event.getAgentId());
            replyEvent.setTimestamp(Instant.now());
            replyEvent.setReplyId(replyId);
            replyEvent.setModel("gpt-4");
            replyEvent.setContent(chunk);
            replyEvent.setChunkIndex(idx);
            replyEvent.setIsLast(false);          // 非最后一个 chunk
            replyEvent.setTokenUsed(totalTokens.get());

            // 发布流式 chunk 事件
            rabbitTemplate.convertAndSend(
                AgentEventMqConfig.EXCHANGE_AGENT,
                ROUTING_KEY,
                replyEvent,
                msg -> {
                    msg.getMessageProperties().setHeader("session_id", sessionId);
                    msg.getMessageProperties().setHeader("trace_id", traceId);
                    msg.getMessageProperties().setHeader("reply_id", replyId);
                    msg.getMessageProperties().setHeader("chunk_index", idx);
                    return msg;
                }
            );
        }).doOnComplete(() -> {
            // ============ 最后一个 chunk，标记 isLast ============
            LLMReplyEvent finalEvent = new LLMReplyEvent();
            finalEvent.setEventId(UUID.randomUUID().toString());
            finalEvent.setSessionId(sessionId);
            finalEvent.setTraceId(traceId);
            finalEvent.setReplyId(replyId);
            finalEvent.setContent("[END]");
            finalEvent.setChunkIndex(chunkIndex.get());
            finalEvent.setIsLast(true);           // 标记流结束
            finalEvent.setTokenUsed(totalTokens.get());

            rabbitTemplate.convertAndSend(
                AgentEventMqConfig.EXCHANGE_AGENT,
                ROUTING_KEY,
                finalEvent
            );

            log.info("[Decision] session={} trace={} LLM 流式回复完毕，共 {} chunks, {} tokens",
                    sessionId, traceId, chunkIndex.get(), totalTokens.get());
        }).doOnError(error -> {
            log.error("[Decision] session={} trace={} LLM 调用失败", sessionId, traceId, error);
            // 发布错误事件通知前端
        }).subscribe();
    }

    private int estimateTokens(String text) {
        // 简化估算：中文约 1.5 字符/token，英文约 4 字符/token
        return Math.max(1, text.length() / 3);
    }
}

// ============ 前端 SSE 接口：消费 llm.reply → 推送给浏览器 ============
@RestController
@RequestMapping("/api/agent")
public class AgentSseController {

    private final ConcurrentHashMap<String, SseEmitter> sessionEmitters = new ConcurrentHashMap<>();

    @GetMapping("/stream/{sessionId}")
    public SseEmitter stream(@PathVariable String sessionId) {
        SseEmitter emitter = new SseEmitter(120_000L);  // 2分钟超时
        sessionEmitters.put(sessionId, emitter);
        emitter.onCompletion(() -> sessionEmitters.remove(sessionId));
        emitter.onTimeout(() -> sessionEmitters.remove(sessionId));
        return emitter;
    }

    // MQ Consumer 收到 llm.reply 后推 SSE
    @RabbitListener(queues = "queue.agent.llm.reply.frontend")
    public void pushToFrontend(LLMReplyEvent reply) {
        SseEmitter emitter = sessionEmitters.get(reply.getSessionId());
        if (emitter != null) {
            try {
                emitter.send(SseEmitter.event()
                    .name(reply.isLast() ? "complete" : "chunk")
                    .data(reply.getContent()));
            } catch (Exception e) {
                sessionEmitters.remove(reply.getSessionId());
            }
        }
    }
}
```

```java
// ============ 记忆模块：旁路消费 tool.result → 写入向量库 ============
@Component
@RequiredArgsConstructor
public class MemoryModule {
    private final EmbeddingService embeddingService;   // Embedding 模型封装
    private final VectorDbClient vectorDbClient;       // QdrantClient / MilvusClient
    private final ObjectMapper objectMapper;

    @RabbitListener(queues = "queue.agent.memory")
    public void onToolResult(ToolResultEvent event) {
        String sessionId = event.getSessionId();
        String traceId = event.getTraceId();

        log.info("[Memory] session={} trace={} 收到 tool.result 事件", sessionId, traceId);

        try {
            // ============ 1. 构建记忆文本 ============
            String memoryText = buildMemoryText(event);

            // ============ 2. 生成 Embedding 向量 ============
            float[] embedding = embeddingService.embed(memoryText);
            // 示例维度：OpenAI text-embedding-3-small = 1536, BGE = 1024

            // ============ 3. 构建 Point 写入 Qdrant/Milvus ============
            PointStruct point = PointStruct.newBuilder()
                .setId(UUID.randomUUID())
                .setVector(embedding)
                .putPayload("session_id", sessionId)
                .putPayload("trace_id", traceId)
                .putPayload("tool_name", event.getToolName())
                .putPayload("content", objectMapper.writeValueAsString(event.getResult()))
                .putPayload("timestamp", event.getTimestamp().toEpochMilli())
                .putPayload("success", event.isSuccess())
                .build();

            // 写入向量库
            vectorDbClient.upsert("agent_memory_collection", List.of(point));

            log.info("[Memory] session={} trace={} tool={} 记忆已写入向量库",
                    sessionId, traceId, event.getToolName());

        } catch (Exception e) {
            log.error("[Memory] session={} trace={} 写入失败，入死信队列重试",
                    sessionId, traceId, e);
            throw new AmqpRejectAndDontRequeueException(e);  // 拒绝 + 不要重回队列
        }
    }

    private String buildMemoryText(ToolResultEvent event) {
        return String.format(
            "Tool: %s | Success: %s | Duration: %dms | Params: %s | Result: %s",
            event.getToolName(),
            event.isSuccess(),
            event.getDurationMs(),
            event.getParams(),
            event.getResult()
        );
    }

    // ============ 记忆检索：下次对话增强上下文 ============
    public List<MemoryRecord> retrieveRelevantMemories(String sessionId, String query) {
        float[] queryEmbedding = embeddingService.embed(query);

        // Qdrant 相似度检索
        List<ScoredPoint> results = vectorDbClient.search(
            "agent_memory_collection",
            queryEmbedding,
            5,    // topK
            0.7f  // score threshold
        );

        return results.stream()
            .map(p -> new MemoryRecord(
                (String) p.getPayload().get("content"),
                p.getScore()
            ))
            .collect(Collectors.toList());
    }
}
```

## Agent 事件消息与传统业务消息对比

| 维度 | 传统业务消息 | Agent 事件消息 |
|---|---|---|
| 消息结构 | 扁平化 JSON（orderId/userId/status） | 嵌套复杂（对话上下文/history[]/CoT 思考链/工具参数） |
| 处理模式 | 单次消费、一次 ACK | 流式处理、LLM 分 chunk 逐步发送 |
| 延迟要求 | 异步最终一致（秒级可接受） | 实时同步（用户等回复，P99 应 < 2s） |
| 消息体大小 | 小而固定（通常 < 1KB） | 大且不固定（多模态 base64/图片 URL，可能 > 100KB） |
| 状态管理 | 单条消息独立、无上下文 | session_id 关联多轮对话、trace_id 链路追踪 |
| 路由策略 | 按业务类型路由（order/user/payment） | 按 session_id + event_type 多级路由 |
| 可靠性 | 高可靠（订单/支付不能丢） | 核心事件高可靠、trace 事件可降级 |
| 消费幂等 | eventId 去重表 | sessionId + chunkIndex 联合去重 |
| 消息中间件 | RabbitMQ（路由灵活）/ Kafka（高吞吐） | 层内 Disruptor + 服务间 RabbitMQ + trace Kafka |

## 一句话总结

**Agent 事件驱动通过"感知→决策→执行→记忆"四模块 MQ 解耦，用 user.message / llm.reply(流式) / tool.result 三级事件串起 LLM 推理链路，session_id 贯穿所有事件保障多轮对话上下文，选型上层内用 Disruptor 纳秒级延迟、服务间用 RabbitMQ Topic Exchange 灵活路由、trace 用 Kafka 高吞吐持久化，记忆模块旁路消费不阻塞主链路。**
