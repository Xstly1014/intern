# 身份与安全层：建立可验证、可撤销、可审计的信任体系

安全层不是网关里的一次 Token 校验，也不是一个独立“安全微服务”。它是一组贯穿客户端、边缘、网关、BFF、业务、数据、消息、交付和运维的控制面与运行时机制。它持续回答五个问题：**谁在访问、以什么凭证、代表谁、能对哪个资源做什么、出现异常后能否限制影响并还原事实。**

## 1. 系统中的位置

![身份与安全层的纵深防御边界](/architecture/security-trust-boundaries.svg)

安全决策分散执行，但责任不能模糊：

| 位置 | 主要安全职责 | 不能替代 |
|---|---|---|
| 客户端 | PKCE、安全存储、反重放、最少采集 | 服务端授权 |
| 边缘/WAF | DDoS、Bot、已知攻击特征、TLS | 业务对象权限 |
| API 网关 | 凭证初检、API Scope、消费者配额 | 订单归属/状态规则 |
| BFF | 会话、CSRF、上下文建立、字段展示裁剪 | 数据所有者最终授权 |
| 业务服务 | 资源级授权、领域不变量、业务审计 | 身份提供商 |
| 数据/平台 | 行列隔离、加密、密钥、备份与供应链 | 应用语义判断 |

“纵深防御”不是每层重复一套相同校验，而是每层基于自己掌握的事实做恰当控制，并使绕过任一层都不会直接获得全部权限。

## 2. 一次受保护请求的信任链

![从认证到资源授权和审计的请求链](/architecture/security-request-chain.svg)

1. 客户端使用正确流程取得短期凭证，不在 URL、日志或不安全存储中暴露它。
2. 边缘终止或透传 TLS，过滤异常流量，但不凭 IP 推断用户身份。
3. 网关严格验证 `iss`、`aud`、签名算法、`kid`、`exp`、`nbf` 与 API Scope。
4. BFF 删除/拒绝外部伪造的身份 Header，建立强类型 `RequestContext`。
5. 服务同时验证调用工作负载和受委托用户，执行资源级授权。
6. 数据访问始终带租户/资源约束，不能先读取再在内存过滤。
7. 访问结果、授权决策和业务变更分别形成受控遥测与审计事实。

## 3. 主体、凭证、会话与权限不是一回事

- **主体 Principal**：用户、设备、服务、任务或代理管理员。
- **凭证 Credential**：证明主体身份的密码、密钥、证书、Token 或 Passkey。
- **会话 Session**：一次登录持续状态，可被撤销、升级认证强度或过期。
- **声明 Claim**：签发时关于主体的事实，不等于永久真实。
- **权限 Permission**：针对动作和资源的决策结果，不能仅凭角色字符串推断。
- **委托 Delegation**：服务或管理员代表另一主体行动，必须保留 actor 与 subject。

## 4. 核心设计原则

### 默认拒绝与最小权限

任何未匹配策略、上下文缺失、租户冲突或策略服务异常都默认拒绝。运行身份只拥有完成当前任务所需权限；开发、运行、发布、审计和密钥管理员职责分离。

### 短期、可撤销、可轮换

长期共享密钥最终会成为无法定位的永久后门。用户 Access Token、服务证书、数据库凭证和云权限尽量短期化；轮换要支持新旧重叠、回滚和使用方盘点，而不是只生成新值。

### 身份与授权端到端传递

“内网请求”不是身份。每一跳识别直接调用方；需要代表用户时传受约束委托，而不是把原始外部 Token 扩散到所有服务。

### 决策靠可信服务端事实

tenant、owner、price、role、approval 等高风险字段不能由请求 Body 决定。客户端版本、设备信息和 IP 可作为风险信号，但不能单独授予权限。

### 可解释和可恢复

授权拒绝应能说明命中了哪个版本策略和缺少什么条件；密钥误发、账户失陷和策略误配都要有撤销、隔离、回滚与取证路径。

## 5. 威胁建模而不是控制清单堆叠

对每条关键数据流记录：资产、主体、信任边界、入口、数据分类、滥用场景、现有控制和剩余风险。重点考虑身份冒用、权限提升、跨租户、数据泄露、篡改、拒绝服务、供应链污染和审计抵赖。

控制必须对应威胁。例如 WAF 可降低通用注入噪声，但无法修复业务服务缺少订单归属校验；TLS 可保护传输，却无法阻止已授权服务批量导出不需要的数据。

## 7. 最小上线基线

- 所有公网 API 明确认证方式、允许的 audience、Scope 和匿名策略。
- 网关到服务、服务到服务都具有可验证的工作负载身份。
- 业务服务按动作、资源、租户执行最终授权，拒绝路径有测试。
- Token、Cookie、密钥和证书有明确生命周期、撤销和轮换演练。
- 租户边界覆盖数据库、缓存、搜索、对象存储、消息和批任务。
- 敏感数据不进入普通日志、Trace、指标标签、错误和非生产环境。
- 依赖与镜像可追溯，有 SBOM、漏洞门禁、签名和紧急升级路径。
- 安全事件有负责人、分级、告警、隔离、恢复、通知与复盘流程。
